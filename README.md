# 🎬 ARItube - Media Downloader \& VLC Streamer

ARItube is a lightweight Python Tkinter GUI application for downloading YouTube videos (MP4), extracting audio (MP3), and streaming high-definition playlists directly in VLC.

## ✨ Features

* **Custom Themes:** Dark Midnight, Cyberpunk, Nord / Slate, Clean Light, Sakura, Sakura2.
* **Direct VLC Streaming:** Stream individual videos or full playlists without downloading.
* **Format Selector:** High-quality MP4 downloads or MP3 audio extraction.
* **Live Progress Bar:** Tracks download percentage, speed, and estimated time remaining (ETA).
* **Directory Picker:** Easily select where your files are saved.
